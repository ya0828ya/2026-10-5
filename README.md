新增一個DocumentViewer視窗，用來顯示和瀏覽文檔內容。
在主視窗MainWindow中新增一個按鈕，點擊後可以打開DocumentViewer視窗。
在DocumentViewer視窗中新增一個RichTextBox，用來顯示文檔內容，並且可以進行編輯。
使用CommandBinding來實現RichTextBox的基本編輯功能，例如複製、剪下、貼上等。
在EditingToolBar中新增文字格式的按鈕，包含加粗、斜體、下劃線、字體顏色等功能。
使用第三方元件ColorPicker來實現字體顏色的選擇功能。
新增變更文字字型的ComboBox，讓使用者可以選擇不同的字型。
新增變更文字大小的ComboBox，讓使用者可以選擇不同的字體大小。
